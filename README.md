# QAJ15-diploma-UnitTest
This project contains unit tests for the RegistrationForm class written in TypeScript. Tests are run with Jest, and coverage can be viewed in an HTML report.

Install
-npm install

Run tests
-npm test
Jest runs tests using the project configuration file.

Run coverage
npm run coverage

HTML test report
After npm test, the HTML test report is created here:

reports/test-report.html

This report can be opened in a browser to view test results in a more readable format.
